# Vytalize Health

> Vytalize Health is a Medicare Accountable Care Organization (ACO) and value-based care company
> headquartered in Hoboken, New Jersey. It partners with independent primary care practices, group
> practices, community health centers and existing ACOs, combining shared-savings economics with a
> clinical decision support product (Vytal Insights), remote and in-home care programs (Vytal Care),
> and a specialist/hospital network layer (Vytal Network).

## Status for agents

Vytalize Health publishes **no public API**. There is no developer portal, no API reference, no
OpenAPI/AsyncAPI/GraphQL contract, no SDK in any public registry, no MCP server and no A2A agent
card on any host it operates. Its software reaches practice partners only through an authenticated
web portal. This file is generated by API Evangelist from the public record; it is not published by
Vytalize Health.

## Products

- [Vytal Insights](https://www.vytalizehealth.com/vytal-insights/): Physician-built clinical decision support that analyzes claims, clinical notes, hospital ADT feeds and social determinants of health to surface point-of-care recommendations.
- [Vytal Care](https://www.vytalizehealth.com/vytal-care/): Remote and in-home programs — transitions of care, chronic disease management, Vytal Care+, home health review — delivered by RN care managers, health coaches, pharmacists and licensed clinical social workers.
- [Vytal Network](https://www.vytalizehealth.com/our-solution/): Specialist, hospital and ancillary provider network management.
